# 16 – Live Operations and Monitoring

## 1. Live Screen Monitoring
The Operations dashboard gives cinema managers real-time visibility into active shows:
- **Real-Time Occupancy Rate**: Visual percentage of locked vs booked vs available seats.
- **Auditorium Status**: Current status (`SHOW_RUNNING`, `INTERMISSION`, `CLEANING_IN_PROGRESS`, `NEXT_SHOW_SEATING`).
- **Live Seat Map**: View real-time seat locks and sales as customers book online.
- **Incident & Maintenance Logging**: Flag broken seats or audio/projector maintenance directly from the live console.
